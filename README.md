# Alumni UI

Landing page do Alumni, uma plataforma para organizar projetos pessoais, acompanhar o progresso e definir os próximos passos.

> **Em construção.** O preview mostra a landing page. As funcionalidades de acesso e cadastro ainda estão pendentes.

[Ver o preview na Vercel](https://alumni-ui-zeta.vercel.app/)

## Tecnologias

Next.js, React, TypeScript e Tailwind CSS.

## Desenvolvimento local

Na raiz do projeto, rode:

```powershell
npm ci
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.
